# ⭕ Tic-Tac-Toe

## 📌 About

A 2-player Tic-Tac-Toe game where players take turns placing `X` and `O` on a 3x3 grid. The game automatically detects a winner across all 8 possible winning patterns (rows, columns, diagonals) — and also correctly detects a draw when the board fills up with no winner.

## ✨ Features

- 🎮 2-player turn-based gameplay (O goes first)
- 🏆 Win detection across all 8 patterns (3 rows, 3 columns, 2 diagonals)
- 🤝 Draw detection when the board fills with no winner
- 🔄 Reset and "New Game" functionality
- 🎨 Clean, minimal UI with a responsive grid layout using `vmin` units

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox, responsive units)
- JavaScript (DOM manipulation, event listeners)

## 🎯 How It Works

- Click any empty cell to place your mark (`O` or `X`, alternating each turn)
- After every move, the game checks all winning patterns for a match
- If someone wins, a congratulations message appears and the board locks
- If all 9 cells fill up with no winner, a "It's a tie!" message appears instead
- Click **New Game** or **Reset Game** to play again
